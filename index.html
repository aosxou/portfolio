PROJECT 01

Pik-Cha!

DSLR 무인 포토부스 — 백엔드

Need
  • 카메라라는 동시 처리 불가능한 단일 리소스에 여러 사용자의 촬영 요청이 몰리는 문제
  • Access Key 발급이 막힌 IAM 제약 환경에서 안전한 업로드·통계 집계 구조 필요
Action
  • 6인 팀 중 백엔드 3인으로 참여해 카메라 제어·업로드·세션 처리 로직과 AWS 인프라 설계 담당
  • Canon EDSDK를 ctypes로 연동하고, EdsdkWorker 큐 기반 스레드 직렬화로 촬영 요청을 순차 처리하도록 설계
  • IAM 역할(SafeRole-sgu-pikcha)이 Access Key 발급을 막은 환경에서 S3 presigned URL 발급 구조 설계
  • DynamoDB의 Scan/Query가 막힌 조건에서 통계 전용 단일 아이템(__STATS__) 누적 방식으로 집계 로직 설계
Result
  • 학교 엑스포 부스 시연을 목표로 개발 진행 중
Python AWS Lambda DynamoDB S3 6인 팀(백엔드 3인)
📅 2026.06 — 진행중 🎓 학교 엑스포 시연 예정
